    Dicas
    
    
      
  • Se aparecer erro de CORS no console do navegador, normalmente o backend não está enviando os headers certos (Access-Control-Allow-*) para a origem desta página.
    • 
      
  • Para requisições com credenciais, o backend precisa setar Access-Control-Allow-Credentials: true e a origem não pode ser "*".
    • 
      
  • Alguns headers/métodos exigem uma preflight (OPTIONS). Se a preflight falhar, a requisição principal nem é enviada.
